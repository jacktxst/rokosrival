# GitHub Usage Guidelines

We will try our best to not introduce bugs, regressions, or incomplete features into the
"main" branch.

When starting out, we will develop a prototype on the main branch. It will be incomplete at first.

Once there's a significant prototype, we will begin using branches and pull requests to integrate all new work. 

Each new feature or bugfix will have a branch maintained by its respective author,
and a pull request will be created for us to review before merging the work.

# Doxygen

We are using Doxygen for docs generation. Doxygen extracts source code comments
as well as class, variable, and function definitions from your code to automatically create a detailed documentation site. (Not an AI technology.)

## Using Doxygen

Doxygen will generate docs for all the classes, variables, and functions automatically,
but these docs won't be very useful without your personally written explanations.

Write a multiline comment above each class, variable and function you write, and Doxygen will incorporate what you wrote into the documentation site.

For Doxygen to work properly, you need to format your header comments as such:


```
/** (<- Note the double asterisk here)

	@brief
	@description

*/
```
